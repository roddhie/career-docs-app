# 履歴書・職務経歴書作成アプリ

ブラウザで履歴書・職務経歴書を編集し、応募先ごとにローカルフォルダへ保存できるアプリです。
文書編集ソフトでのレイアウト調整の負担を減らし、提出用のPDFを出力できます。

## 主な機能

- **履歴書**　学歴・職歴・免許・資格を年・月・内容が横並びの入力欄で編集できます。基本情報タブで選択した顔写真は、履歴書のプレビューとPDFに反映されます。
- **職務経歴書**　職務要約・技術・スキル・職歴・プロジェクト・自己PRを編集できます。技術・スキルは入力欄と書類の両方で表形式になり、職歴とプロジェクトも書類では表にまとまります。項目の順序や、項目・職歴・プロジェクトの改ページ位置を指定できます。
- **書類管理**　応募先ごとの書類を保存・読み込み・複製できます。共通プロフィールから新しい書類も作成できます。
- **プレビューとPDF出力**　日付・年月・行数などのチェック結果を確認し、Chromeの印刷機能でPDFに保存できます。

## 使用技術

React / TypeScript / Vite / File System Access API

バックエンド・データベース・認証は使用していません。
書類データは、利用者が選択したローカルフォルダに保存します。

## ローカルでの起動

開発環境は Windows、Google Chrome、Node.js v24.22.3、npm 11.19.1 です。
Node.js 24系とnpmを用意し、リポジトリのルート（`package.json` があるフォルダ）をPowerShellで開いて、次のコマンドを実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

ターミナルに表示されたローカルURLをChromeで開いてください。
終了するときは、開発サーバーを起動したターミナルで Ctrl + C を押します。

開発時は以下のコマンドで、Lintと、型チェックを含むビルドを実行できます。

```powershell
npm.cmd run lint
npm.cmd run build
```

ビルド結果は `dist/` に生成されます。ローカルで確認するには `npm.cmd run preview` を実行します。

## 使い方

1. リポジトリ外に個人データ用のフォルダを用意し、「保存フォルダを選択」で指定します。
2. 起動時に表示されるサンプルをもとに、「基本情報」「履歴書」「職務経歴書」タブで入力内容を編集します。
3. 顔写真を載せる場合は、「基本情報」タブの「顔写真」でJPEGまたはPNG形式の画像（5 MB以下）を選択します。
4. 「編集中の書類を保存」を押します。保存済みの書類は「読み込む書類」で選び、「選択した書類を読み込む」で開きます。

別の応募先で本文も使う場合は「別企業用に複製」を選び、志望動機などを応募先に合わせて見直します。
氏名・連絡先・学歴・職歴・資格・顔写真などを再利用する場合は、「基本情報」タブで「現在のプロフィールを共通用に保存」を押し、「共通プロフィールから新規作成」を使います。
複製・新規作成した書類も「編集中の書類を保存」で保存します。

## 保存とバックアップ

| 保存フォルダ内のファイル | 内容 |
| --- | --- |
| `application-<書類ID>.json` | 応募先ごとの履歴書・職務経歴書の編集データ |
| `profile.json` | 共通プロフィール |
| `application.json` | 初期形式の書類。引き続き読み込み可能 |
| `photos/` | 選択した顔写真のコピー |

顔写真の選択・解除後は「編集中の書類を保存」を押すと、写真の参照先が書類のJSONに反映されます。「この書類の写真を解除」を押した後も、画像ファイルは他の書類で使えるよう `photos/` に残ります。
共通プロフィールの更新内容を既存の書類にも反映したい場合は、その書類を開いて編集してください。

再起動・リロード後は、保存フォルダを選び直して書類を読み込みます。
バックアップや移行の際は、写真の相対パスを保つため、JSONと `photos/` を含む保存フォルダごとコピーしてください。個人情報を含むファイルや提出用PDFはリポジトリ外で管理してください。

## PDF出力

「プレビュー」タブで「履歴書を表示」または「職務経歴書を表示」を選びます。
チェック結果を確認してエラーを修正したら、「表示中の書類を印刷・PDF保存」を押してください。

Chromeの印刷画面で以下を確認します。

- 保存先：PDFに保存
- 余白：デフォルト
- ヘッダーとフッター：オフ
- 背景のグラフィック：オフ

PDFには現在の画面の内容が反映されます。PDFの保存先は印刷画面で指定し、後から編集する場合はアプリの「編集中の書類を保存」でJSONも保存してください。

履歴書は厚生労働省の履歴書様式例を参考にしたA4・2ページ構成です。
提出前に、文字の欠け・重なり・空白ページや改ページの位置を確認し、履歴書が2ページに収まっていることを確かめてください。

## 現在の制約

- 自動保存には対応していません。
- 同じ書類を複数のタブやウィンドウで同時編集する運用には対応していません。
- 履歴書の学歴・職歴は入力で合計21行までです。プレビューでは「学歴」「職歴」「以上」が加わり、最大24行になります。免許・資格は8行までです。
- 内容の正しさや、文章量によるページ超過は自動判定しません。
- 印刷ボタンのエラーチェックは、ブラウザの Ctrl + P には適用されません。
- クラウド同期やWebサービスとしての公開には対応していません。
